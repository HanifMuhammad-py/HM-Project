MINI PROJECT 001
Warung POS - Simple Point of Sale System

Description :
A lightweight command-line Point of Sale (POS) system built in Python, 
designed for small food & beverage businesses (UMKM). Supports order 
entry with unique transaction IDs, real-time order listing, and daily 
revenue tracking.

Built with: Python 3 | Dictionary | Random ID Generation | Datetime

Features:
- Add orders with auto-generated transaction ID
- View all orders in formatted table
- Calculate total daily revenue
- Timestamp for each transaction



MINI PROJECT 002
CashFlow Tracker - Daily Income & Expense Recorder

Description :
A simple yet effective command-line cash flow management tool for small 
businesses. Enables owners to record daily income and expenses, view 
full transaction history, and generate end-of-day financial reports 
with profit/loss status.

Built with: Python 3 | Dictionary | Random ID Generation

Features:
- Record income and expense transactions separately
- View categorized transaction history
- Daily financial report with profit/loss indicator
- Clean formatted table output
